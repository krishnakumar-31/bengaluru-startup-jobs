# Data Directory

This directory is designated for seed datasets, geographic polygon data (Bengaluru ward/locality boundaries), and sample data structures.

## Planned Contents
- `seed_startups.sample.json`: Schema reference for startup company metadata.
- `seed_jobs.sample.json`: Schema reference for job postings.
- `bengaluru_hubs.json`: Coordinates and boundaries for Bengaluru startup clusters (Koramangala, Indiranagar, HSR Layout, Whitefield, Bellandur, Electronic City, etc.).

*Note: In compliance with initial phase requirements, real companies, job listings, salaries, and private data are not committed.*
